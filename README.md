# Laboration 3 - CSS-Preproccesorer 

Denna applikation har skapats för att demonstrera praktisk användning av SASS, modern front-end utveckling utifrån en automatiserad arbetsprocess och publicering via GitHub Pages.
Detta genom SCSS använding med variabler, mixins, nesting och selector inheritance som ligger bakom webbplatsens grafiska funktionalitet, som exempelvis sidans både mörka och ljusa profil.  

# Laboration 4 - Grafiska effekter med CSS

Denna applikation har sedan vidareutvecklats för att demonstrera skapandet av grafiska effekter och animationer med CSS samt dynamisk funktionalitet med JavaScript. Fokus har legat på att använda @keyframes, transition och transform för att skapa tre olika typer av animationer, inklusive rörliga objekt och effekter som triggas av användarinteraktion.
Kod för design och animationer har skrivits i SASS, där befintliga filer har utvecklats och kompletterats med en partial för animeringar som syns på sidan ”animering”. 

# Laboration 5 - Dynamiska webbplatser

Denna applikation har vidareutvecklats ytterligare för att demonstrera dynamisk funktionalitet med JavaScript samt visuell presentation av data genom diagram. Fokus har legat på att skapa två nya undersidor, ”Diagram” och ”Karta”, där användaren kan interagera med webbplatsen och få information presenterad på ett visuellt sätt. På sidan ”Diagram” visas statistik för de sex mest sökta kurserna och de fem mest sökta programmen HT25 på Mittuniversitetet i Sundsvall med stapel- och cirkeldiagram. Diagrammen genereras med Chart.js och datan hämtas via Fetch API och async/await. På sidan ”Karta” kan användaren söka efter en plats via ett textfält och se platsen markerad på en dynamisk karta, där koordinater hämtas via Nominatim API. Kod för interaktivitet och diagram har dokumenterats med JSDoc, och dokumentationen är publicerad online. All styling och layout har fortsatt att byggas med SASS, där befintliga filer har utvecklats och kompletterats för att passa de nya funktionerna.
